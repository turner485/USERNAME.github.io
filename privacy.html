Privacy Policy

Twitch Clipper is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

It uses the YouTube Data API with the youtube.upload permission. It does not collect, store, sell or share data from any other user.

The OAuth token is stored only on the owner's computer and is used only to upload videos. Access can be revoked at any time at https://myaccount.google.com/permissions.
