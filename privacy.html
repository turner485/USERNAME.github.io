Privacy Policy

Last updated: 30 October 2026

YouTube API Services

Twitch Clipper uses YouTube API Services to upload videos. By using Twitch Clipper you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms.

Google Privacy Policy: https://policies.google.com/privacy.

What data is accessed

Twitch Clipper is a personal tool used only by its owner. With the owner's permission (OAuth scope youtube.upload), it uploads the owner's own video files and their titles and descriptions to the owner's own YouTube channel. It does not read, collect or use any other YouTube data, and it accesses no data from any other user.

How data is stored and shared

The only data stored is the OAuth access token, saved on the owner's own computer. It is never sent anywhere except to Google to make upload requests. No data is sold, shared with third parties, or used for advertising. Twitch Clipper uses no cookies or tracking.

Revoking access and deleting data

Access can be revoked at any time through the Google security settings page: https://security.google.com/settings/security/permissions. On revocation, or on request, the stored token is deleted from the owner's computer within 7 days. Uploaded videos stay on YouTube and can be deleted in YouTube Studio.

TikTok

Twitch Clipper also uses the TikTok Content Posting API (scopes user.info.basic and video.upload) to send the owner's own videos to the owner's own TikTok inbox as drafts. It stores only the TikTok access token, on the owner's computer. Access can be revoked in the TikTok app under Settings and privacy > Security > Manage app permissions.
